# Contributing

Thank you for helping. A few things to know first:

- **License.** ArtisanHub Link is licensed under the GNU Affero General Public License v3.0 only.
  Contributions are accepted under the same license, and the project is not offered under any other
  license.
- **Sign-off.** Add a `Signed-off-by:` line to each commit (`git commit -s`), confirming you wrote the
  change or have the right to submit it under this license, as in the
  [Developer Certificate of Origin](https://developercertificate.org/).
- **Review.** Every change from outside the team is reviewed before it is merged. Releases are built
  from `main` by the release workflow and signed only after a maintainer approves them (see
  [CODE_SIGNING.md](CODE_SIGNING.md)).
- **Security.** Report security problems privately, as described in [SECURITY.md](SECURITY.md).
- **Writing.** No em dashes in code, comments or documents; CI checks for them.
